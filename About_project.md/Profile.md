# Профиль Пользователя (User Profile)

Профиль в StreamVibe — это личный кабинет пользователя, где он может управлять своими данными, настройками безопасности и просматривать статус своего аккаунта.

## Управление Персональными Данными
Настройки профиля (страница `/user/settings`) обрабатываются с помощью React Server Actions, что позволяет безопасно отправлять данные на сервер без создания дополнительных API-роутов.

1. **Загрузка Аватара**
   - Для хранения изображений профиля используется сервис **UploadThing**.
   - Когда пользователь выбирает картинку, она загружается напрямую в облачное хранилище UploadThing.
   - После успешной загрузки (callback `onClientUploadComplete`), в БД обновляется поле `image` в модели `User`.

2. **Смена Пароля**
   - Пользователь должен ввести текущий пароль и новый пароль.
   - Сервер (Server Action `updatePassword`) извлекает хэш пароля из базы, сравнивает его с текущим (с помощью `bcrypt.compare`). Если совпадает — новый пароль хэшируется и сохраняется в базу.

3. **Смена Email и Номера телефона**
   - Смена контактных данных (Email, Phone) защищена двухфакторной логикой.
   - При запросе на смену телефона, сервер генерирует 6-значный код, записывает его в таблицу `PhoneUpdateToken` (со сроком действия 1 час) и отправляет на текущий email пользователя (через Resend / Nodemailer).
   - Пользователь вводит полученный код, происходит проверка (поиск токена в БД по коду), и в случае успеха данные профиля обновляются.

## Авторизация (NextAuth)
Все данные профиля извлекаются из базы данных на основе сессии (Session), предоставляемой **NextAuth.js**.
- При входе в настройки, вызывается `await auth()` для получения текущего пользователя.
- Если сессии нет, пользователь автоматически перенаправляется на страницу логина (`/auth/login`).
- Использование сессий на стороне сервера гарантирует, что пользователь может изменить только свои собственные данные.
