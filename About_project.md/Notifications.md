# Система Уведомлений (Notifications)

Система уведомлений в StreamVibe предназначена для информирования пользователей о важных событиях: новостях платформы, статусе подписки, ответах поддержки и т.д.

## Архитектура системы

1. **База данных (Prisma Schema)**
   Уведомления хранятся в таблице `Notification`. Каждое уведомление привязывается к конкретному пользователю (через `userId`). 
   - Имеет поля `title`, `message`, `isRead` (прочитано ли), `createdAt`.
   - Если уведомление глобальное, оно может рассылаться через фоновую задачу или создаваться для всех пользователей циклом.

2. **Админ-панель (`/admin/notifications`)**
   Администраторы могут создавать новые уведомления. Через специальную форму вводится заголовок и текст сообщения. Форма обращается к Server Action или API-роуту, который записывает данные в базу.

3. **Отображение на клиенте (UI)**
   - На панели навигации (Navbar) присутствует иконка «Колокольчик».
   - При клике на неё происходит запрос к базе данных (через Server Component или React Query/fetch), который извлекает список уведомлений, где `userId` равен ID текущего пользователя.
   - Также происходит подсчет непрочитанных уведомлений (`isRead: false`), чтобы показать бейдж с количеством новых сообщений.

   ![Меню уведомлений](/images/notifications-menu-example.png)
   *Пример открытого меню уведомлений пользователя*

4. **Взаимодействие**
   - При открытии уведомлений, клиентский компонент отправляет запрос на сервер для отметки уведомлений как прочитанных (меняет `isRead` на `true`).
   - Пользователь может удалить уведомление (запрос на удаление записи из БД).

## Как собираются данные?
Данные для уведомлений могут собираться двумя путями:
1. **Ручное создание:** Администратор пишет текст в админке, нажимает «Отправить», и система создает записи `Notification` в БД.
2. **Системные триггеры:** Если у пользователя заканчивается подписка или получен ответ в поддержке (Ticket), система (например, webhook Stripe) может автоматически вызвать функцию `createNotification(userId, message)` для создания записи в БД.
