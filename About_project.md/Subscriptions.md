# Система Подписок (Subscriptions)

Система подписок управляет доступом пользователей к премиум-контенту StreamVibe. Подписки реализованы с использованием Stripe в качестве платежного шлюза.

## Как работает подписка?

1. **Выбор плана**
   Пользователь заходит на страницу подписок (`/subscriptions`) и видит доступные тарифные планы (Basic, Standard, Premium). При выборе плана происходит вызов API `/api/stripe/checkout`.

2. **Оплата через Stripe**
   - Бэкенд генерирует сессию оплаты (Checkout Session) через Stripe API.
   - Пользователь перенаправляется на безопасную страницу оплаты Stripe.
   - После успешной оплаты пользователь возвращается на платформу.

3. **Сбор данных и Вебхуки (Webhooks)**
   - Когда платеж проходит успешно, Stripe отправляет POST-запрос на специальный эндпоинт в приложении (Stripe Webhook: `/api/stripe/webhook`).
   - Сервер верифицирует подпись вебхука, чтобы убедиться, что запрос пришел от Stripe.
   - После этого в базе данных (в таблице `User` или `Subscription`) обновляются данные:
     - `stripeCustomerId`: ID клиента в Stripe.
     - `stripeSubscriptionId`: ID подписки.
     - `subscriptionStatus`: статус (active, past_due, canceled).
     - `subscriptionEndDate`: дата окончания.

4. **Проверка доступа**
   При попытке запустить видео (`Play Now`), система проверяет объект пользователя из БД (или сессию). Если `subscriptionStatus === 'active'`, доступ разрешается. Если нет — пользователю предлагается оформить подписку.

## Управление подпиской в Профиле

![Управление подпиской](/images/subscription-profile-example.png)
*Пример раздела управления подпиской в профиле пользователя*

В настройках профиля пользователь может увидеть текущий статус подписки. Также есть возможность управлять подпиской (отменить или изменить план). Кнопка "Управление подпиской" генерирует ссылку на Stripe Customer Portal (Billing Portal), где пользователь может отвязать карту или поменять тариф без необходимости писать для этого кастомный интерфейс.
