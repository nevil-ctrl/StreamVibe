# Описание Админ-панели (Admin Panel)

Админ-панель в StreamVibe — это полностью кастомное решение, написанное вручную с использованием Next.js (App Router) и Tailwind CSS, без использования готовых CMS (таких как Strapi или WordPress). Она интегрирована прямо в приложение и работает напрямую с базой данных через Prisma ORM.

## Как это работает?

![Дашборд Администратора](/images/admin-dashboard-example.png)
*Пример интерфейса дашборда администратора*

Доступ к админ-панели (по маршруту `/admin`) имеют только пользователи с ролью `ADMIN`. Проверка роли происходит на уровне Middleware и Server Components, что гарантирует безопасность.

### Основные разделы админки:

1. **Дашборд (`/admin/dashboard`)** 
   - Отображает общую сводку: количество пользователей, активные подписки, недавние запросы в поддержку.
   
2. **Аналитика (`/admin/analytics`)**
   - **Сбор данных:** Данные для графиков собираются напрямую из базы данных (PostgreSQL) с помощью агрегационных запросов Prisma (например, подсчет регистраций по дням, количество просмотров, доходы от подписок). 
   - Данные визуализируются с помощью библиотек чартов (например, Recharts/Chart.js).

3. **Пользователи (`/admin/users`)**
   - Полное управление пользовательской базой: просмотр профилей, управление ролями, блокировка (бан) нарушителей, сброс паролей.
   - Данные подтягиваются через Prisma `prisma.user.findMany()`.

4. **Уведомления (`/admin/notifications`)**
   - Позволяет администраторам создавать и массово рассылать системные уведомления пользователям (новости, акции, предупреждения).

5. **Поддержка (`/admin/tickets`)**
   - Обработка обращений пользователей (Support Tickets). Администраторы могут отвечать на вопросы, менять статус тикетов (Open, Resolved) и связываться с пользователями по email или телефону.

## Откуда берутся данные?

Все данные в админ-панели генерируются на основе реальных действий пользователей в приложении. Когда пользователь регистрируется, покупает подписку, оставляет отзыв или запускает фильм — всё это сохраняется в PostgreSQL. Админ-панель просто делает выборки (SELECT) из этих таблиц и красиво выводит их администратору. Никаких сторонних сервисов для хранения внутренней структуры не используется — всё "in-house".
