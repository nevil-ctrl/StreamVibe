# Интеграция PostHog (Аналитика)

**PostHog** — это мощная платформа для продуктовой аналитики, встроенная в StreamVibe. Она используется для отслеживания поведения пользователей, сбора метрик и тестирования новых фич.

## Для чего нужен PostHog в проекте?

1. **Аналитика посещаемости и сессий (Pageviews & Sessions)**
   - PostHog автоматически отслеживает, на какие страницы заходят пользователи (маршруты Next.js).
   - Записывает сессии (Session Recording): можно в виде видео посмотреть, как пользователь взаимодействует с интерфейсом, где у него возникают трудности, куда он кликает. Это критически важно для улучшения UX/UI.

2. **Сбор пользовательских событий (Custom Events)**
   - В коде мы можем отправлять кастомные события. Например: `posthog.capture('video_played', { movieId: 123 })` или `posthog.capture('subscription_started')`.
   - Эти данные собираются в дашборды внутри интерфейса PostHog и помогают понять конверсию (например, сколько людей перешли со страницы подписок к успешной оплате).

3. **Feature Flags (Флаги функций)**
   - PostHog позволяет включать и выключать определенный функционал для части пользователей (A/B тестирование) без деплоя нового кода.
   - Например, мы можем обернуть новую кнопку в проверку: `if (posthog.isFeatureEnabled('new-player-ui')) { ... }`. 

## Как это реализовано в коде?

- PostHog подключается на уровне всего приложения (в `app/layout.tsx` или через специальный провайдер `PostHogProvider`).
- Инициализируется с ключом проекта (Project API Key) из `.env` файлов (`NEXT_PUBLIC_POSTHOG_KEY`).
- Для того чтобы аналитика учитывала переходы без перезагрузки страницы (ведь Next.js использует SPA-роутинг), в приложении настроено перехватывание изменения URL (через `usePathname` и `useSearchParams`), которое триггерит событие `$pageview`.

**Безопасность данных:** Конфиденциальные данные пользователей (например, пароли или токены) никогда не отправляются в PostHog. Для записи сессий (Session Replay) чувствительные поля ввода скрываются (masking), чтобы в аналитику попадали только звездочки.
